# NS-BOS Kernel

**NGARi Sovereign Business Operating System: Kernel**

The NS-BOS Kernel is a minimal, auditable runtime for AI agents on edge hardware the user owns. It provides encryption at rest, a keyed audit log, operator identity with PIV/CAC cards, a sandbox for agent code, local inference clients and inter-agent messaging, with no cloud dependency.

## Quick Start

Requires **Linux** and **Python >= 3.10**. (Not 3.9: the kernel's annotations use `X | None`
unions, evaluated at import time with no `from __future__ import annotations`, which raises
`TypeError` below 3.10. Not macOS or Windows.)

```bash
# One-shot installer. Read it first, it is short: ./install.sh
./install.sh

# ...or by hand:
python3 -m venv .venv && . .venv/bin/activate
pip install -r core/kernel/requirements.txt
NGARI_DATA_DIR=~/.ngari/kernel python -m core.kernel
```

The kernel orchestrates inference. **It ships no model.** Point it at a runtime
(Ollama, llama.cpp, vLLM) and weights you supply.

## Design Principles

1. **Sovereign by default**: air-gap mode is on unless it is turned off
2. **Minimal kernel**: it stores, isolates, records and enforces; behavior is layered above
3. **Auditable**: every kernel action is recorded in a keyed, hash-chained audit log
4. **Hardware-agnostic**: runs on aarch64 and x86_64
5. **Accountable**: operators are named people with PIV/CAC cards and roles; an AI agent is sponsored by one
